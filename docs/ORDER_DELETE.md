# 自动删除采购单据

自动删除扫描登录后的线下采购单据列表。候选来自当前筛选范围内所有分页中可点击的行内「删除」按钮。没有按钮或按钮不可用的行会跳过。

## 操作步骤

1. 运行 `python main.py`，选「自动删除」并登录。脚本只读展示候选行和数量。
2. 核对范围和候选。若要缩小范围，在浏览器中调整筛选，回到任务窗口输入 `r` 刷新预览。
3. 确认这些行均应删除后，按提示输入 `删除 N 条`。程序点击每行的删除按钮，识别该次打开的单条删除弹窗，再点击确认。直接回车可取消。
4. 查看成功、跳过和失败汇总。结果不明确时检查网页后再决定是否重跑。

默认命令 `python order_delete.py` 登录后只读预览。加 `--execute` 可在确认数量后执行。`--via-casmart` 可从商城入口开始登录。

## 定位、分页及结果

- 点击范围限于单据行内可用的「删除」「删除订单」或「删除单据」按钮。确认限于该次点击产生的唯一删除弹窗。其他操作、批量弹窗或结构不明确时停止。
- 翻页后等行数据更新，再从实际列表找下一条。同名或显示内容相同的行可以一起预览并逐条处理。
- 执行前重新核对预览范围。删除后复查列表，只有数量及其余可见行与预期一致才记录成功。筛选或列表内容发生变化、实际删除结果不明时停止本批。
- 删除和弹窗确认各点击一次。支持常见网页弹窗、同源 iframe 和浏览器原生确认。未知分页、虚拟滚动表格、多个候选表格或弹窗会停止。
- 本地运行记录位于 `outputs/order-delete/run-*.jsonl`。记录可能包含业务商品名称，目录由 Git 忽略。

## 验证范围

本机合成页面没有单号列，验证了跨页删除、相同显示行、禁用按钮跳过、异步刷新、过滤变化和弹窗处理。真实腾讯导出及线上授权验证未执行，本次没有操作真实单据。
