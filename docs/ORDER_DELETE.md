# 错误导入订单批量删除

本功能由 `order_delete.py` 独立提供，桌面任务菜单可直接启动。登录复用 `songshen.py` 的学校认证、Edge、列表检查和等待机制；原送审脚本、附件模块及旧飞书脚本保留。

## 使用步骤

1. 在项目目录运行 `python main.py`，选择“删除错误导入订单”。
2. 每行填写一个本人确认导入错误的完整单据编号或订单号，最多 100 个。不支持通配符、商品名或按行号选择。编号须为 2–100 位字母、数字或 `. _ / -`。
3. 默认自动识别唯一编号列。若页面同时显示多个编号列，在输入窗口明确选择实际填写的列。支持“单据编号、单据号、订单号、订单编号、采购单号、采购单据编号”。
4. 完成学校验证。程序只读扫描当前筛选条件下的全部分页，展示每个指定编号、原页面位置、各列内容，以及可删除或跳过的原因。列表仅证明编号和按钮匹配，是否为错误导入仍由本人判断。
5. 核实所有可删除条目均在预期范围后，在二次确认窗口输入 `删除 N 条`，再点击确认按钮。取消、关闭窗口或只读模式均不会点击订单行的删除按钮。
6. 程序逐条重新扫描、核对内容、点击该行删除、确认新弹窗，再完整扫描分页，确认目标编号未再出现后才记录成功。

执行期间请保持当前页面及筛选不变。无可用删除按钮的单据记为跳过，其中可能包括已送审单据；程序不会借此认定其余单据均应删除。任务结束后浏览器保持打开，桌面任务窗口按回车关闭。

## 命令行

```powershell
# 默认只读：不打开删除弹窗，不点击确认。
python order_delete.py --order-id SYNTHETIC-001 --order-id SYNTHETIC-002

# 明确编号列；扫描完成后仍须本人输入确认短语。
python order_delete.py --order-id SYNTHETIC-001 --id-column 单据编号 --execute

# 不填写编号则先显示输入窗口；认证入口配置沿用 docs/LOGIN.md。
python order_delete.py --execute
```

`--via-casmart` 可改用原商城登录入口。没有跳过二次确认的参数，也没有“删除全部未送审”的入口。附件分类程序不能触发本功能。

## 定位、分页及停止条件

- 编号只与明确表头对应单元格的完整文字精确匹配，区分大小写，不从整行文字猜测编号。多个相同编号会阻止整批执行。
- 支持普通 HTML table、简单 Element UI / Ant Design 表格及最多三层同源 iframe。编号列必须唯一，表头与行单元格须一一对应。固定列副本、多层或合并表头、复杂合并业务行、未能关联表头的独立表体和可识别的虚拟滚动组件会停止。未列出的页面结构不在支持范围，需先做只读适配。
- 支持 Element UI、Ant Design、Layui 的明确上一页/下一页控件；无分页控件时范围为当前完整表格。始终先回首页，再向后扫描，最多 200 页。不能确认首页、翻页内容未更新、分页内容重复或超出上限均视为扫描不完整。
- 删除后订单可能移到前一页，页数也可能减少。因此不缓存行号或跨页复用旧元素，每条执行前后均重新完整扫描。列表地址、来源、登录、窗口、筛选值、每页数量和排序发生变化时停止。
- 只点击目标行内文字明确为“删除／删除订单／删除单据”的唯一有效按钮。删除和确认均只点击一次，不使用送审流程的多种点击重试，也不调用审批流选择或送审确认函数。
- 确认限于本次点击后新出现的唯一删除弹窗，支持 DOM 弹窗、弹窗内部同源 iframe 和浏览器原生确认。确认按钮须在弹窗内部，且文字明确为“确定／确认／确定删除／确认删除／删除”。与送审、审批、全部或批量有关的弹窗、编号不符、多个弹窗、多个确认按钮或未知弹窗均不自动确认。
- 弹窗未关闭、目标仍存在、系统报告失败或完整分页复查失败时，当前条记为失败，后续条记为跳过。本条可能已受理，必须人工查看记录和列表后决定是否重新运行；程序不会自动重试或自动补删。

确认后完整分页中找不到目标编号，是本功能的界面核验依据；没有接入服务端删除 API 或回滚机制。平台实际表头、分页和弹窗仍需授权后的真实页面验证。若平台使用独立新浏览器窗口作为业务弹窗，本版本会停止，不能自动确认。

## 本地记录

每次创建独立的 `outputs/order-delete/run-日期时间-随机值.jsonl`，记录指定编号、预览内容、二次确认结果、点击意图、成功／跳过／失败及原因。登录失败或预扫描中止也会记录已指定编号的失败结果。控制台显示数量汇总和记录路径。

目录已被 Git 忽略。记录可能包含真实单号及业务内容，应只在本人授权的本地目录保存。异常仅记录自定义停止原因或异常类型，不输出带认证参数的 URL、凭证或整页快照。
