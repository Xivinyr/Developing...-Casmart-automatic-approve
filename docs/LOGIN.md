# Casmart 与学校统一认证登录

## 运行

在项目目录中激活本机已有的独立环境：

```powershell
conda activate reimbursement_auto
python songshen.py --login-only
```

`--login-only` 只进行登录并进入线下单据列表，不查找或点击送审按钮。确认实际学校认证流程可用后，正常使用 `python songshen.py`，继续原有送审与翻页流程。

1. 弹窗分别填写 Casmart 和学校统一认证的账号密码。两处账号可以不同；任一处同时留空，即在浏览器手动登录该网站。
2. 脚本打开线下单据入口，遇到商城登录表单时填写商城凭证；出现“去登录”等统一认证提示时点击进入学校认证。
3. 在 `https://uis.smu.edu.cn` 填写学校凭证后等待本人输入验证码并点击登录。微信登录、其他二次验证也由本人操作，不自动识别或提交验证码。
4. 确认已回到 Casmart 会员中心的登录状态后，沿用本次返回的新会话参数进入线下单据列表。不会在学校登录页仍未完成时强制跳走，也不再使用旧的 10 秒倒计时。

默认最多等待 600 秒，可修改 `songshen.py` 的 `LOGIN_WAIT_SECONDS`。登录未完成或列表再次要求认证时，本次停止，不进入送审。每个窗口内的每处登录表单最多自动填写一次、商城最多自动提交一次；账号密码错误时可直接在浏览器修正并手动登录，避免反复重试。

## 保存与清除

勾选“记住账号密码”后，两个网站的信息分别保存到 `%LOCALAPPDATA%\CasmartAuto\credentials.bin`；下次运行会自动预填弹窗。取消勾选后继续，或点击“清除保存”，会删除本机保存信息。关闭或取消弹窗不会更新保存内容。

使用 Windows 当前用户的 DPAPI 加密整个凭证内容，写入文件与临时文件的都是密文，不增加密码库依赖。通常只能在同一台设备、同一 Windows 用户下解密，换设备需重新填写；同一 Windows 用户运行的程序仍可调用系统解密。依据：[Microsoft CryptProtectData 文档](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)。

源码不包含个人账号、学校用户标识或密码，不读取旧飞书浏览器配置，也不保存新的浏览器登录态。自动填写仅用于明确列出的 Casmart HTTPS 域名及学校认证 HTTPS 域名；遇到其他验证站点时由本人操作。

## 验证范围（2026-11-26）

- 合成验证：新增 15 项登录/保存测试与原 9 项附件测试，共 24 项通过。覆盖分站填写、验证码保留、认证回跳窗口、超时停止、仅登录不送审、新会话参数、错误来源拒绝，以及虚构账号的真实 Windows DPAPI 加解密、损坏检测、清除与原子替换失败恢复。
- 真实腾讯导出验证：本次未执行，与登录适配分开记录。
- 线上授权验证：本次未填写或提交真实账号，未执行学校认证、真实采购操作或送审。学校公开登录页未能通过当前工具读取；表单定位基于用户截图与可见输入框，具体线上 DOM、验证码与回跳兼容性需本人用 `--login-only` 验证。上述合成结果不能替代线上验证。

测试命令：`python -B -m unittest discover -s tests -v`。仅新增标准库模块，Python 运行依赖仍为 Selenium。
