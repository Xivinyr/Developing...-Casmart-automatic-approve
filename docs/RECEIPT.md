# 采购单据签收

签收使用独立任务。输入是一个包含 `manifest.json` 的附件分类批次文件夹。程序用供应商名称定位 Casmart 的合并签收单，再用单内每件商品的全名匹配分类清单和实际文件夹。

## 操作步骤

1. 先用腾讯网页选区或本地 XLSX 分类附件。发票缺失时先补齐，再选新的批次。
2. 运行 `python main.py`，选「采购单据签收」和保存分类结果的批次文件夹。
3. 登录后，程序扫描当前筛选范围的全部分页。核对终端列出的供应商，选择本次处理的一家。同一家有多个可用的签收入口时，先在网页核对并缩小筛选范围。
4. 程序打开该供应商的签收表单，列出单内全部商品、对应文件夹及文件。核对无误后输入「上传」。同一签收单中，类型与内容都相同的附件上传一次，例如两件商品共用的一张发票。
5. 等每个文件都显示上传成功，在浏览器复核附件，再输入「签收」。收到明确的网页成功提示后任务才报告完成。

分类清单有供应商字段时，程序用它区分不同供应商的同名商品。旧批次中没有供应商字段的商品须能唯一匹配，终端会提示人工核对这些材料的归属。签收单内有重名、任一商品找不到唯一目录或明细无法完整读取时，整张单据暂停。程序同时检查目录名、路径、文件格式、大小和哈希。网页采用其他表头时，可用 `--supplier-column` 或 `--product-column` 指定供应商列或商品列。

默认要求订单截图、支付记录、发票和开箱实物图四类齐全。支持一个共用上传区，也支持按四种材料标明名称的独立上传区。PDF 若不被网页接受，先核对网页格式要求。已有附件、上传失败、表单商品无法核对或结果不明时，任务会停下来。取消最终签收时，已上传的附件可能还在网页暂存。

## 预检与验证

~~~powershell
# 本地查看能用的商品文件夹
python order_receipt.py --folder "outputs\run-示例"

# 登录，只读查看有哪些供应商可选
python order_receipt.py --folder "outputs\run-示例" --check-list
~~~

`--execute` 允许在核对并输入确认语句后上传及签收。`--manifest` 也可指向该目录的清单文件。

使用断网 Edge 的合成页面验证供应商合并行、商品目录匹配、共用或分栏上传和最终签收。仍需用真实腾讯导出验证分类，并核对 Casmart 实际的供应商表头、签收明细、上传格式和回执。
