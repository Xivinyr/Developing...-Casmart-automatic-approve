# 采购单据签收

签收使用独立任务。输入是一个包含 `manifest.json` 的附件分类批次文件夹。程序先打开可用的签收入口，从表单读取供应商名称，再汇总清单中该供应商的全部商品附件。每次运行处理一个签收表单。

## 操作步骤

1. 用腾讯网页选区或本地 XLSX 分类附件，补齐缺失发票。
2. 运行 `python main.py`，选「采购单据签收」和分类批次文件夹。旧清单缺少供应商时，选择含供应商名称列的原采购表 XLSX。支持“*供应商名称”等必填表头。
3. 登录后，程序直接查找可用签收按钮。当前页没有时延时复查并继续翻页，打开第一个可用入口。
4. 程序读取签收表单的供应商，列出清单中对应的全部商品、文件夹及文件。核对后输入「上传」。类型与内容都相同的附件上传一次，例如多件商品共用的发票。
5. 等每个文件都显示上传成功，在浏览器复核附件，再输入「签收」。收到明确的网页成功提示后任务才报告完成。

每条商品记录通过 `supplier` 字段保存供应商。旧清单按原表中的完整商品名或分类时使用的发票文件名补齐，补齐前版本保存在同目录。同名商品属于多家供应商时需先核对归属，无法匹配的记录会提示人工核对。上传前检查目录名、路径、文件格式、大小和哈希。网页使用其他供应商字段名时，可用 `--supplier-column` 指定。

列表通过可用签收按钮定位。签收页的供应商字段或与清单中唯一供应商名称的文字匹配结果用于材料归属。表单出现多个供应商时暂停。

默认要求订单截图、支付记录、发票和开箱实物图四类齐全。支持共用上传区或标明四种材料名称的独立上传区。已有附件、缺材料、供应商改变、上传失败或回执不明时暂停。取消最终签收时，已上传的附件可能仍在网页暂存。

## 预检与验证

~~~powershell
# 本地查看能用的商品文件夹
python order_receipt.py --folder "outputs\run-示例"

# 从原采购表补齐清单中的供应商
python order_receipt.py --folder "outputs\run-示例" --supplier-source "原采购表.xlsx"

# 登录，只读查看有哪些供应商可选
python order_receipt.py --folder "outputs\run-示例" --check-list
~~~

`--execute` 打开签收表单，核对并输入确认语句后上传及签收。`--manifest` 也可指向该目录的清单文件。

使用断网 Edge 的合成页面验证按钮定位、延迟加载、分页、供应商匹配和上传。实际网页的供应商展示、上传格式和回执仍需现场验收。
