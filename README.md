# Casmart 报账自动化系统
在项目目录运行主程序：

```powershell
conda activate reimbursement_auto
python main.py
```

在窗口中选择自动送审、采购单据签收、自动删除、仅验证登录、腾讯网页选区分类或本地 XLSX 附件分类。分类结果及删除记录可以从窗口中的“打开输出目录”查看。

日常开发目录为 `E:\Sync_Active\90_Developing...-Casmart-automatic-approve`，整个项目放在自己的子文件夹中。原 D 盘目录保留为本次迁移前的副本。

## 登录与本机保存账号密码

配置本机入口后，脚本直接打开南方医科大学统一认证。输入学校账号密码并勾选“记住账号密码”，下次运行时会在登录表单可输入后自动填写。验证码、微信或其他验证由本人在浏览器中完成，认证回跳后进入线下单据列表。

原命令行入口仍可用，`python songshen.py --login-only` 可单独验证登录。

- [登录步骤、保存位置与验证范围](docs/LOGIN.md)

## 采购单据签收

从“采购单据签收”选择分类批次文件夹。程序直接打开可用的签收入口，从签收页读取供应商，再汇总清单中该供应商全部商品的图片和发票。旧清单可选择原采购表补齐供应商字段。核对上传预览后上传，文件全部成功后再确认签收。

- [选择清单、只读验证和签收步骤](docs/RECEIPT.md)

## 自动删除

选择“自动删除”。登录后只读扫描当前筛选条件下的全部分页，预览有可用“删除”按钮的行。输入窗口要求的 `删除 N 条` 后，程序逐条点击该行的删除按钮并确认弹窗。

没有可用删除按钮的行会跳过。请核对预览是否涵盖你准备删除的所有行。调整浏览器筛选后，输入 `r` 更新预览。页面变化或结果不确定时，程序会停止供你检查。

- [使用步骤、支持的页面结构与验证范围](docs/ORDER_DELETE.md)
- 命令行只读预览：`python order_delete.py`
- 本地逐条结果：`outputs/order-delete/run-*.jsonl`（禁止提交到 Git）

## 腾讯文档附件下载与分类

在线任务可在当前腾讯工作表自动选取 T 到 W 列的当月数据并分类，任务窗口输入 `a` 即可尝试。可填月份或批次名，将结果分开放置。若网页能明确识别选区发票的下载入口，程序会尝试补取原始 PDF。手头已有 XLSX 时，也可使用独立的本地分类入口。

- [使用说明、配置与边界](docs/ATTACHMENTS.md)
- [实验结果与方案比较](docs/EXPERIMENTS.md)
- 快速运行：`python -m attachments xlsx "data/报账表.xlsx" --config config.example.json`
- 测试：`python -m unittest discover -s tests -v`

真实腾讯文档导出、附件质量及 OAuth 权限尚待样例验证；合成测试结果不代表线上成功。请勿将报账数据或浏览器登录状态提交到此公开仓库。
